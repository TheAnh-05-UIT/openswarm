# Deployment provenance and scope

This deployment repository targets independent project implementations, not the
unlicensed recovered OpenSwarm/HPE source. It carries configuration, operational
and validation glue, and one project-owned numeric bootstrap artifact. Runtime
launchers are generated by the selected Independent SWOP image, not copied from
legacy images or external task folders.

The bootstrap artifact SHA-256 is
`590525b9b37b66b74a21c492a910a27b30ca030d2d15bac64a1b4203ae314702`.
Its format is bounded JSON metadata plus float32 tensors; it is not executable
code, pickle, an external dataset, or a downloaded pretrained model.

Deployment files follow the independent project's MIT license included here.
Docker images and their OSS components retain their respective licenses and
notices. This repository does not claim that SBOM/source-access/distribution
obligations for the images have been satisfied. PUBLIC RELEASE remains BLOCKED.
Monitoring/Grafana are excluded from the default deployment.

No endorsement or API compatibility with HPE/OpenSwarm is claimed.
